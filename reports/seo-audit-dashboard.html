P2 High www.rankrgv.com redirects with a 307 (Temporary) — should be 301/308 ▼

When you visit www.rankrgv.com, the server responds with a 307 Temporary Redirect to https://rankrgv.com/. HTTP 307 signals to Google that this redirect could change at any time, so it should not permanently consolidate PageRank. A 301 or 308 Permanent Redirect tells Google to pass full link equity and treat the destinations as the same resource.

Why This Matters

Any backlinks pointing to www.rankrgv.com are currently leaking link equity. Google may not fully consolidate the two versions of the domain. As the site builds backlinks over time, this becomes an increasingly significant ranking drag.

How to Fix
  1. In your Vercel project dashboard, go to Settings → Domains
  2. Ensure www.rankrgv.com is set to redirect to rankrgv.com as a Permanent Redirect (308)
  3. If Vercel is auto-generating this redirect, check vercel.json for a redirects config and set "permanent": true
  4. Verify with: curl -sI http://www.rankrgv.com/ | grep -E "HTTP/|Location:" — should show 301 or 308
